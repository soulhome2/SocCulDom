# Прототип «Безопасное образование» v0.2

`index.html` — кликабельный прототип веб-интерфейса по ТЗ [SafeEducation_Specification.md](../Specification/SafeEducation_Specification.md) с правками из [Корректировка дашборда](../Specification/Корректировка%20дашборда%20SafeEducation_Specification.md). Что изменилось и почему — [SafeEducation_Prototype_v0.2.md](../Specification/SafeEducation_Prototype_v0.2.md).

Один самодостаточный файл: открывается в браузере без сервера и интернета. Стиль — ONE PSIM Prototype Kit (новая версия: `kit.css` + `kit.js`), светлая и тёмная темы, русский и английский. Компоновка рабочего места событий и шапки — по образцу Incident Manager. Данные — фикстура, демо-время начинается в 10:40.

## Экраны

Объект: Главная · Пост охраны и Обход (только роль «Пост охраны») · Видеонаблюдение · Посещаемость · Приём и выдача детей (детский сад) · События · Перекличка (не у директора).
Учёт и регламенты: Люди и пропуска · Журналы · Отчёты · Обслуживание.
Администрирование: Конфигурация (всё, что хранится на сервере; позже — отдельный конфигуратор) · Аудит.

Режимы «Эвакуация», «Учебная тревога» и «ЧС» перестраивают главный экран.

## Шапка

- режим объекта — меню переключения;
- язык (Русский / English), выбор запоминается в браузере; на телефоне — в меню пользователя;
- параметры прототипа (ползунки): профиль, роль, состояние блоков данных, поток проходов, потеря связи, демо-события;
- тема, пользователь, часы.

## Исходники

`index.html` собирается — руками не править.

```
src/
  body.html        каркас страницы
  app.css          слой страницы поверх токенов кита (--color-*)
  i18n-en.js       английский каталог: ключ — русская строка
  selftest.js      самопроверка (?selftest)
  js/00-icons.js … 99-boot.js   модули приложения; склеиваются по порядку в одну IIFE
vendor/one-psim/   kit.css, kit.js, InterVariable.woff2 — из ONE.PSIM.PrototypeKit
```

Правила: текст интерфейса — только через `t('Русская строка {x}', {x})`; иконки — только литералом `ic('имя')` (динамические перечислены в `00-icons.js`); имена, введённые людьми (ФИО, классы, камеры), не переводятся.

## Сборка и проверки

- `python tools/build_prototype.py` — собрать; `--check` — проверить, что собран из текущих исходников.
- `python tools/run_selftest.py` — самопроверка: 36 шагов, по шагу на каждое замечание корректировки и ключевые требования ТЗ; без Playwright — открыть `index.html?selftest`.
- `python tools/check_ui.py [--shots <папка>]` — 14 экранов × 2 темы × 1440/360 px: контраст, выход за край, кнопки без подписи.
- `python tools/check_i18n.py` — все строки интерфейса имеют английский перевод (статический разбор + обход экранов на английском).
