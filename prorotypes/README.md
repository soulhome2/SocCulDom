# Прототип «Безопасное образование»

`index.html` — кликабельный прототип веб-интерфейса по ТЗ [SafeEducation_Specification.md](../Specification/SafeEducation_Specification.md). Один самодостаточный файл: открывается в браузере без сервера и интернета. Стиль — ONE PSIM Prototype Kit, светлая и тёмная темы. Данные — фикстура, демо-время начинается в 10:40.

## Экраны

Главная (дашборд, режим объекта) · Пост охраны · Видеонаблюдение · Посещаемость (сводка, журнал, требует проверки, динамика, карточка ученика) · Приём и выдача детей (профиль «Детский сад») · События · Перекличка (экран телефона учителя) · Люди и пропуска · Журналы · Отчёты · Обслуживание · Настройки · Аудит.

Режимы «Эвакуация», «Учебная тревога» и «ЧС» перестраивают главный экран.

## Параметры прототипа (кнопка с ползунками в шапке)

- профиль: школа, детский сад, колледж;
- роль: директор, зам. по безопасности, пост охраны, классный руководитель;
- состояние блоков данных: данные, загрузка, пусто, ошибка;
- поток проходов СКУД, автоматические отметки учителей при эвакуации, потеря связи;
- события для демонстрации: сработка СПС, ответ родителя «не знаю», драка, неисправность камеры.

## Сборка и проверки

`index.html` собирается из `src/` (app.js, app.css, body.html, selftest.js) и `vendor/` (токены, компоненты и шрифт ONE PSIM, иконки Octicons) — руками не править.

- `python tools/build_prototype.py` — собрать; `--check` — проверить, что собран из текущих исходников.
- `python tools/run_selftest.py` — самопроверка (шаги по требованиям ТЗ); без Playwright — открыть `index.html?selftest`.
- `python tools/check_ui.py [--shots <папка>]` — контраст, выход за край на 360 px, кнопки без подписи.
