1. В левой части в списке "Объект" необходимо убрать пункт "Пост Охраны".

3. ==🟠!!!== Вопрос: в объекте "Видеонаблюдение" есть группы камер. Откуда берутся эти группы? Из интеллекта или их нужно вручную привязывать в дашборде? Если отдельно, то необходимо добавить инструментарий привязки камер к группам камер. ==🟠!!!==
4. Объект "Посещаемость" -> вкладка "Сводка". В пункте "Присутствие" на шкале нужно дополнительно отображать % посещения.
5. Объект "Посещаемость" -> вкладка "Сводка". Добавить сортировку по столбцам.
6. Объект "Посещаемость" -> вкладка "Журнал". Добавить сортировку по столбцам.
7. Объект "Перекличка"  - статус "отсутствует - семейные обстоятельства" заходит на имя.

8. Объект "Люди и пропуска" -> вкладка "Держатели пропусков". Отсутствует инструмент по добавлению людей.
9. Объект "Люди и пропуска" -> вкладка "Держатели пропусков". Добавить сортировку по столбцам.
10. Объект "Люди и пропуска" -> вкладка "Посетители". Отсутствует инструмент по добавлению людей.
11. Объект "Люди и пропуска" -> вкладка "Посетители". Добавить сортировку по столбцам.
12. Добавить новый объект "Обход". В нем должен быть размещен чек-лист с обозначением мест, которые нужно обойти. Напротив каждого пункта чек-листа должна стоять кнопка "проверено" и "не проверено". Данный объект должен отображаться только пользователям с правами "Пост охраны".
