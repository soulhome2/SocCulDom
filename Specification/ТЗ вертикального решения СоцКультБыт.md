## Общие требования к Система:

- Система должна реализовывать СРВИ как отдельный функциональный сегмент со своей моделью данных, настройками, правами доступа и журналами. Сегмент предназначен для информационного взаимодействия с администрацией учреждения.

1. Система должна предоставлять через СРВИ:
	- живое видео и видеоархив с камер в объёме выданных прав;
	- события видеоаналитики в режиме реального времени;
	- журнал событий и результаты поиска по архиву;
	- время и место события.

2. Система должна вести неизменяемый журнал всех действий в СРВИ, в том числе:
	- просмотры видео;
	- поисковые запросы;
	- выгрузки;
	- изменения прав и списков контроля.

3. Просмотр журнала СРВИ должен быть доступен только "Администрации учреждения".

4. Пользовательский интерфейс СРВИ должен быть реализован в виде WEB-интерфейса, доступного через браузер без установки клиентского программного обеспечения на рабочие места, так как СРВИ располагается в закрытом комплексе.

5. Система должна ограничивать или предоставлять пользователям СРВИ приоритетный доступ к управлению PTZ-камерами согласно их правам доступа.

6. Система должна обеспечивать бесшовный приоритетный доступ СРВИ к системам видеонаблюдения удалённых объектов мониторинга с сохранением их автономии, без объединения распределённых объектов в единую сеть.

7. ==🟠Система должна обеспечивать резервирование видеоархива систем видеонаблюдения в СРВИ.==

8. ==🟠Операторы и администраторы подчинённых систем видеонаблюдения не должны иметь возможности получать данные о действиях операторов СРВИ, в том числе о перехвате живого видео, архива и управления PTZ-камерами.==

## Общие требования к интерфейсу

- Адаптивный веб-интерфейс.
- Автообновление ключевых показателей без перезагрузки страницы (интервал 10–30 секунд).
- Единый стиль, соответствующий корпоративным цветам платформы.
- Возможность перехода из любого блока к детальной информации.

## Блок «Ключевые показатели»

Отображаемые данные:
- Количество людей, находящихся в здании в текущий момент (по данным СКУД).
- Общее количеств детей в школе по спискам

Функционал:
- Клик по показателю открывает детализированный список (кто находится в здании / кто отсутствует).
- Показатели обновляются автоматически.

## Блок «Состояние систем»

Отображаемые данные:
- Статус видеонаблюдения.
- Статус СКУД.
- Статус охранной сигнализации.
- Статус пожарной сигнализации (СПС).

Функционал:
- Цветовая индикация: зелёный — норма, жёлтый — есть неисправность, красный — сработка / тревога.
- При наведении на неисправный пункт выводится количество неисправных устройств.
- Переход к списку неисправностей по клику.

## Блок «Видеонаблюдение (Live)»

Отображаемые данные:
- Сетка из 4 ключевых камер по умолчанию (вход, коридор, столовая, двор — настраивается).
- Индикатор онлайн-статуса.

Функционал:
- Клик по камере открывает её в увеличенном режиме. В увеличенном режиме можно стрелочками переключить на следующую камеру.
- Кнопка «Все камеры» открывает полный список камер с возможностью выбора сетки (1/4).
- Возможность добавления/удаления камер в избранное.
- Быстрый переход в архив выбранной камеры.

## Блок «Последние события»

Отображаемые данные:
- Лента последних 8–15 событий.
- Для каждого события: тип, время, место (камера/зона), краткое описание.
- Цветовая/иконная индикация типа события.

Типы событий:
- Тревоги (охрана, пожар, кнопка помощи).
- События аналитики (драка, лежащий человек, скопление и др.).
- Проходы СКУД (опционально, с возможностью отключения).
- Неисправности оборудования.

Функционал:
- Клик по событию открывает связанное видео и/или фото.
- Кнопка «Все события» открывает полный журнал с фильтрами.
- Возможность подтверждения/отметки события как «обработано».

## Блок «Сводка по посещаемости»

Отображаемые данные:
- Общее количество обучающихся.
- Количество присутствующих и процент.
- Количество отсутствующих и процент.
- Мини-график динамики отсутствий за неделю.

Функционал:
- Переход к детальному журналу посещаемости.
- Фильтрация по классам.
- Выгрузка отчёта.

## Панель быстрого доступа слева

Кнопки перехода в разделы:
- Главная страница
- Видеонаблюдение
- Журнал посещаемости
- Журнал событий
- Права

Функционал:
1. Переход на вкладку видеонаблюдение предоставляет доступ к полному списку видеокамер. Клик по камере открывает ее в увеличенном размере, в таком состоянии появляются на камере появляются стрелочки перехода на следующую камеру
2. Переход на вкладку журнал посещаемости отображает:
	  - Суммарное количество детей в школе
	  - Количество присутствующих детей
	  - Список детей с фильтром: дата, класс и имя фамилия. В списке отображается максимум 50 строк.
  
3. Журнал посещения также отображает суммарное количество детей за день
4. Переход на вкладку "Журнал событий" предоставляет доступ к списку 50 последних событий. Над журналом расположены фильтры СКУД.
5. Переход на вкладку "Права" предоставляет доступ к списку персонала и учащихся. Выводится информация: ФИО, Права, Состояние и функциональные кнопки "заблокировать" и "разблокировать"
	  - Над списком находится "поиск"
	  - Возле поиска находится счетчик с общим количеством обладателей карт.
